= Fluxo de trabalho de instalação de hardware para switches de cluster Cisco Nexus 9336C-FX2 e 9336C-FX2-T
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Siga este fluxo de trabalho para instalar e configurar o hardware dos switches de cluster Cisco Nexus 9336C-FX2 e 9336C-FX2-T.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"]link:setup-worksheet-9336c-cluster.html["Preencha a planilha de cabeamento"]
[role="quick-margin-para"]
A planilha de cabeamento de exemplo fornece exemplos de atribuições de portas recomendadas dos switches aos controladores.  A planilha em branco fornece um modelo que você pode usar para configurar seu cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"]link:install-switch-9336c-cluster.html["Instale o interruptor"]
[role="quick-margin-para"]
Instale os switches 9336C-FX2 e 9336C-FX2-T.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"]link:install-switch-and-passthrough-panel-9336c-cluster.html["Instale o switch em um gabinete NetApp ."]
[role="quick-margin-para"]
Instale os switches 9336C-FX2 e 9336C-FX2-T e o painel de passagem em um gabinete NetApp , conforme necessário.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatro"]link:install-switch-and-passthrough-panel-9336c-cluster.html["Revisar a cablagem e a configuração."]
[role="quick-margin-para"]
Revise o suporte para portas Ethernet NVIDIA , requisitos de FEC de 25 GbE e informações sobre recursos TCAM.
