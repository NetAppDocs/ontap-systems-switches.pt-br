= Guia de início rápido para sistemas AFX, cluster, storage e switches compartilhados
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para começar a usar os sistemas AFX, cluster, armazenamento e switches compartilhados, você instala componentes de hardware e configura seu switch.

A implantação do switch envolve o seguinte fluxo de trabalho.

[role="quick-margin-para"]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Seis"]Configuração completa do ONTAP
[role="quick-margin-para"]
Após instalar e configurar os controladores e switches do seu sistema ONTAP , você deve concluir a configuração do seu armazenamento no ONTAP.  Acesse as instruções a seguir de acordo com a sua configuração de implantação.

[role="quick-margin-list"]
* Para implantações do ONTAP , consulte https://docs.netapp.com/us-en/ontap/task_configure_ontap.html["Configurar ONTAP"^] .
* Para implantações do ONTAP com MetroCluster , consulte https://docs.netapp.com/us-en/ontap-metrocluster/["Configure o Metrocluster com o ONTAP"^] .
