= Visão geral da coleta de logs
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Com a coleta de logs configurada, você pode habilitar a coleta horária de dados periódicos que são coletados pelo AutoSupport e solicitar logs de suporte detalhados.

A coleta de logs ajuda você a solucionar problemas em switches de rede, reunindo automaticamente logs e dados de diagnóstico. Você pode coletar dados periodicamente de forma agendada por meio do AutoSupport ou acionar a coleta sob demanda quando precisar de logs detalhados para solucionar problemas específicos. Os logs coletados fornecem visibilidade sobre a integridade do switch, alterações de configuração e eventos de rede.

Consulte link:config-log-collection.html["Configurar coleta de logs"] para obter mais detalhes.
