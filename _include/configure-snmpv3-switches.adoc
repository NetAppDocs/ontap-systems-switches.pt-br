[NOTE]
====
* O SNMPv3 só é compatível com o ONTAP 9.12.1 e versões posteriores.
* O ONTAP 9.13.1P12, 9.14.1P9, 9.15.1P5, 9.16.1 e versões posteriores corrigem esses dois problemas:
+
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-82891["Para monitoramento de integridade do ONTAP em switches Cisco , o tráfego SNMPv2 ainda pode ser observado após a migração para o SNMPv3."^]
** link:https://kb.netapp.com/on-prem/ontap/OHW/OHW-Issues/CONTAP-119131["Alertas falsos positivos de ventoinha e energia do switch quando ocorrem falhas SNMP."^]




====
.Sobre esta tarefa
Os seguintes comandos são usados ​​para configurar um nome de usuário SNMPv3 em switches *Broadcom*, * Cisco* e * NVIDIA*:

[role="tabbed-block"]
====
.switches Broadcom
--
Configure um nome de usuário SNMPv3 NETWORK-OPERATOR em switches Broadcom BES-53248.


NOTE: A partir do ONTAP 9.20.1, você pode configurar a autenticação SHA-512 nos switches Broadcom.

* Para *nenhuma autenticação*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR noauth
----
* Para *autenticação MD5/SHA/SHA-512*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512]
----
* Para autenticação *MD5/SHA/SHA-512 com criptografia AES/DES*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512] [priv-aes128|priv-des]
----


O comando a seguir configura um nome de usuário SNMPv3 no lado do ONTAP :

[source, cli]
----
security login create -user-or-group-name <snmpv3-user> -application snmp -authentication-method usm -remote-switch-ipaddress <address>
----
O comando a seguir estabelece o nome de usuário SNMPv3 com o CSHM:

[source, cli]
----
cluster1::*> system switch ethernet modify -device <switch-name> -snmp-version SNMPv3 -community-or-username <snmpv3-user>
----
.Passos de exemplo
. Configure o usuário SNMPv3 no switch para usar autenticação SHA e criptografia AES-128:
+
[listing, subs="+quotes"]
----
(sw1)(Config)# *snmp-server user SNMPv3shaAes128 NETWORK-OPERATOR auth-sha priv-aes128*

.switches Cisco
--
Configure um nome de usuário SNMPv3 `<snmpv3-user>` nos switches Cisco Nexus.


NOTE: A partir do ONTAP 9.20.1, é possível configurar a autenticação SHA-512 ou SHA-256 em switches Cisco.

* Para *nenhuma autenticação*:
+
[source, cli]
----
snmp-server user <snmpv3-user> NoAuth
----
* Para *autenticação MD5/SHA/SHA-256/SHA-512*:
+
[source, cli]
----
snmp-server user <snmpv3-user> auth [md5|sha|sha-256|sha-512] <auth-password>
----
* Para autenticação MD5/SHA/SHA-256/SHA-512 com criptografia AES/DES*:
+
[source, cli]
----
snmp-server user <snmpv3-user> AuthEncrypt auth [md5|sha|sha-256|sha-512] <auth-password> priv [aes-128|des] <priv-password>
----


O comando a seguir configura um nome de usuário SNMPv3 no lado do ONTAP :

[source, cli]
----
