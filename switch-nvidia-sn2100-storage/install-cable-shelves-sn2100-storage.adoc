= Conecte os compartimentos de unidades NS224 como armazenamento conectado a switch para os switches de armazenamento NVIDIA SN2100
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Conecte os gabinetes de unidades NS224 como armazenamento conectado a switches usando os switches de armazenamento NVIDIA SN2100 quando o armazenamento conectado diretamente não for adequado para sua configuração.

* O cabo NS224 aciona as prateleiras através dos switches de armazenamento:
+
https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580["Informações para cabeamento de gavetas de unidades NS224 conectadas a switches"^]

* Instale seus switches de armazenamento:
+
https://docs.netapp.com/us-en/ontap-systems-switches/index.html["Documentação dos interruptores AFF e FAS"^]

* Confirme o hardware compatível, como switches de armazenamento e cabos, para o modelo da sua plataforma. Consulte a link:https://hwu.netapp.com/["Hardware Universe"^] para obter detalhes.
