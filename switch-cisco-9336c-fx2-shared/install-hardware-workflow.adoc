= Fluxo de trabalho de instalação de hardware para switches compartilhados Cisco Nexus 9336C-FX2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Siga este fluxo de trabalho para instalar e configurar o hardware de um switch compartilhado Cisco Nexus 9336C-FX2.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"]link:cable-9336c-shared.html["Preencha a planilha de cabeamento"]
[role="quick-margin-para"]
A planilha de cabeamento de exemplo fornece exemplos de atribuições de portas recomendadas dos switches aos controladores.  A planilha em branco fornece um modelo que você pode usar para configurar seu cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"]link:install-9336c-shared.html["Instale o interruptor"]
[role="quick-margin-para"]
Instale o switch 9336C-FX2.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"]link:install-switch-and-passthrough-panel-9336c-shared.html["Instale o switch em um gabinete NetApp ."]
[role="quick-margin-para"]
Instale o switch 9336C-FX2 e o painel de passagem em um gabinete NetApp , conforme necessário.
